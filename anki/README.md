# Flashcards do Anki

Os baralhos distribuídos neste diretório usam o formato `.apkg`, formato de pacote do Anki.

## Como importar

1. Instale e abra o [Anki](https://apps.ankiweb.net/) no computador.
2. Baixe ou localize o arquivo `.apkg` deste repositório.
3. No Anki, escolha **Arquivo > Importar** e selecione o arquivo; alternativamente, abra o `.apkg` com o Anki.
4. Confirme a importação. O baralho aparecerá na lista de baralhos.

Para sincronizar o baralho com outros dispositivos, configure a sincronização pela sua conta AnkiWeb após a importação.
